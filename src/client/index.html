ℹ️ About FF-ICE & SWIM

FF-ICE (Flight and Flow Information for a Collaborative Environment) is the global ICAO standard (Doc 9965) replacing legacy ICAO 4444 paper/AFTN flight plans with modern, machine-consumable 4D trajectories.

Key Pillars:

  • 4D Trajectory Core: Trajectories are represented as four-dimensional coordinates $(Latitude, Longitude, Altitude, Timestamp)$, enabling precise Top-of-Climb (TOC), Top-of-Descent (TOD), and 3D FIR boundary crossings.
  • FIXM Standard: Uses Flight Information Exchange Model (FIXM v4.2+) XML and JSON payloads for semantic consistency.
  • GUFI: Every flight is assigned an immutable RFC 4122 UUID v4 Globally Unique Flight Identifier.
  • SWIM Compliant: Implements System-Wide Information Management (Doc 10039) Yellow Profile REST interfaces with OpenAPI 3.0.
  • Strategic Deconfliction: Automated 4D separation check against active traffic (enforcing 5 NM horizontal, 1,000 ft vertical, and 5-minute temporal separation).

Geographical Scope:

UK & Irish Airspace (London FIR `EGTT`, Scottish FIR `EGPX`, Shannon FIR `EISN`, Shanwick Oceanic `EGGX`) utilizing official UK & Irish Aeronautical Information Publications (AIP).
